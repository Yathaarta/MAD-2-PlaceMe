This is a Placement Portal Application made as a part of MAD-2 course in IIT-Madras BS data science degree.

This Application is designed to ease the process of placements happening in Universities/Institutes by making a large part of the Students & Company Interaction and Management of Placement Drives by Institute, A software application based experience.
